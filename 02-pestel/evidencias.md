# Evidencias PESTEL

## 1. Protección de datos personales

### Qué lo sustenta
El sistema propuesto gestionaría información relacionada con préstamos y responsables de los elementos del laboratorio. Esto hace posible que se requiera registrar información de estudiantes o docentes.

### Qué todavía es un supuesto
El caso no especifica qué datos personales serán almacenados ni confirma que el sistema vaya a registrar información personal de los usuarios.

### Evidencia necesaria
Se debe revisar el proceso actual de préstamo y consultar qué información se registra actualmente. También se debe revisar la normativa aplicable al tratamiento de datos personales.

---

## 2. Costos de mantenimiento

### Qué lo sustenta
El caso establece que algunos elementos del laboratorio requieren mantenimiento.

### Qué todavía es un supuesto
No se conocen los costos de mantenimiento, la frecuencia de las reparaciones ni la cantidad de equipos que requieren mantenimiento.

### Evidencia necesaria
Se deberían consultar registros históricos de mantenimiento, costos de reparación, cantidad de equipos reparados y frecuencia de las intervenciones.
