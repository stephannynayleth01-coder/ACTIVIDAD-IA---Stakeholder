# Decisiones del Lean Canvas

## Squad 4 — Sistema de inventario para laboratorio

## 1. Análisis del problema

A partir del caso, el analisís del equipo concluyo en que los principales problemas están relacionados con:

- Información desactualizada de los equipos.
- Falta de trazabilidad de préstamos y movimientos.
- Desconocimiento del estado operativo de los elementos.
- Dificultades para tomar decisiones.

También se tuvo en cuenta que saber dónde está un equipo no significa saber si está disponible para usarlo.

---

## 2. Alternativas consideradas

Durante la construcción del Lean Canvas se analizaron varias opciones para algunos bloques.

### Problema

Se consideraron opciones como:

- Falta de inventario.
- Falta de control de préstamos.

Estas opciones se descartaron porque eran muy generales y no cubrían todo lo que muestra el caso.

### Solución

Se consideraron opciones como:

- Un inventario básico.
- Un sistema enfocado únicamente en préstamos.
- Un sistema únicamente para mantenimiento.

Estas opciones se descartaron porque solo resolvían una parte del problema.

### Propuesta de valor

Se consideraron ideas como:

- Tener un sistema facil de usar.
- Digitalizar el inventario con herramientas como bases de datos o hojas de calculo.
  
Estas opciones se cambiaron por que no explicaban y no aportaban un valor para el sistema que requiere el laboratorio.

### Ventaja injusta

Se consideraron opciones como:

- Tener una interfaz intuitiva y tecnologias modernas.
- Tener acceso desde varios dispositivos.

Estas opciones se descartaron porque pueden ser fácilmente copiadas por otros sistemas y no representan una diferencia importante.

### Segmentos de clientes

Se consideraron algunos actores como:

- Responsables financieros.
- Proveedores externos.
- Personal de otras áreas de la institución.

Estas opciones no se dejaron porque no tienen una relación directa con el uso diario del sistema.

### Métricas

Se consideraron métricas como:

- Cantidad total de equipos.
- Cantidad de equipos disponibles.
- Cantidad de equipos en mantenimiento.

Estas métricas se modificaron porque solo muestran cantidades y no permiten ver con claridad el impacto del sistema.

### Estructura de costos

Se consideraron elementos como:

- Publicidad.
- Costos de ventas.
- Comisiones comerciales.

Estas opciones se descartaron porque el sistema está pensado para uso interno de una institución y no con fin de ser un producto comercial.

# Flujo de ingresos

Se consideraron opciones como:

- Suscripciones mensuales.
- Pago por usuario o rol de usuario.
- Venta del sistema a otras instituciones.

Estas opciones se descartaron porque el caso no plantea un modelo de negocio comercial o pensado para extender a otras instituciones.

---

## 3. Crítica al Lean Canvas

Durante el análisis se hicieron varios cambios para que el Lean Canvas quedara más relacionado con el caso:

- Se cambiaron las métricas para medir mejor el estado y uso de los equipos.
- Se organizaron los segmentos de clientes según el tipo de usuario.
- Se evitó definir una tecnología específica sin tener información que la justificara.
- Se cambió la ventaja injusta para enfocarla en tener en un solo lugar la información de ubicación, estado, disponibilidad, préstamos y mantenimientos.
- El flujo de ingresos se manejó como impacto o beneficio esperado, ya que se trata de un sistema para una institución.

---

## 4. Uso de IA

### Herramienta utilizada

Cursor Grok — septiembre de 2026.

### Propósito

La IA se utilizó para:

- Proponer opciones para los bloques del Lean Canvas.
- Comparar alternativas.
- Detectar posibles errores.
- Ayudar a organizar la información.

### Ciclo 1 — Generar

La IA propuso diferentes opciones para:

- Problemas.
- Segmentos de clientes.
- Métricas.
- Canales.
- Ventaja injusta.
- Flujo de ingresos.

### Ciclo 2 — Criticar

El equipo revisó las opciones propuestas y realizó cambios según el caso.

Entre las decisiones tomadas estuvieron:

- Cambiar métricas basadas solo en cantidades por métricas relacionadas con actualización, disponibilidad y préstamos.
- Organizar los segmentos en usuarios operativos, usuarios de uso y usuarios de decisión.
- No usar una aplicación móvil como canal.
- Manejar el flujo de ingresos como impacto esperado del sistema.

### Ciclo 3 — Decidir

Con base en las opciones propuestas por la IA y las sugerencias del equipo, se ajustaron los bloques hasta llegar a la versión final del Lean Canvas.
